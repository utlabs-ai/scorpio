zh: 别的账号的人不再看到你的 agent 的屏幕：/read、/keys、/text 和 daemon 的自动报告里，屏幕只给你自己和你的 agent，别人只看到一行说明；发出前像密钥的字符串会替换成 [hidden]。agent 收到的消息正文每行前面加了「│」。
en: People of other accounts no longer see your agents' screens: in /read, /keys, /text and the daemon's reports, the screen goes to you and your agents only, and others see one line; strings that look like keys are replaced with [hidden] before sending. Message text an agent receives now has "│" at the start of each line.
