# server

Cloudflare Worker, one Durable Object per topic, and the D1 migrations. Licensed under AGPL-3.0 (see the repository `LICENSE`).

To run your own, deploy from the repository root: the Deploy button or `npm run build && npm run deploy` there, as [docs/self-hosting.md](../docs/self-hosting.md) describes. For working on it, `npm run dev` here starts it locally with the root `wrangler.jsonc` (`npm run migrate:local` first).
